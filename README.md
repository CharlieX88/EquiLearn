# 🚀 EquiLearn — AI-Powered Virtual Stock Market Learning Platform

EquiLearn is a gamified, full-stack MERN application designed to help beginners learn the Indian stock market without risking real money. Inspired by "Duolingo for Finance", it combines virtual paper trading, structured lessons, and an AI Mentor to build financial confidence.

## 🔗 Live Demo
- **Frontend (Live App):** [https://equi-learn-phi.vercel.app](https://equi-learn-phi.vercel.app)
- **Backend API:** [https://equilearn-634q.onrender.com/api/v1/health](https://equilearn-634q.onrender.com/api/v1/health)

*(Note: The backend is hosted on Render's free tier. If it's inactive, the first request might take 30-50 seconds to load.)*

## ✨ Key Features

- **📈 Virtual Trading Terminal:** Practice real-time simulated trading with ₹10,00,000 virtual cash. Features live chart updates, market/limit orders, and portfolio tracking.
- **🧠 AI Stock Guide (Groq API):** Analyzes live stock data and user portfolios to teach trading psychology, risk management, and technical analysis without giving direct financial advice.
- **📚 21+ In-Depth Lessons:** Covers Foundations, Investing Basics, Trading Fundamentals, Fundamental Analysis, and Risk & Mindset. Includes quizzes and real-world examples.
- **🎮 Gamification:** Earn virtual coins, maintain daily streaks, unlock badges, and compete on the global leaderboard.
- **🔐 Secure Authentication:** JWT-based auth with fully functional "Forgot/Reset Password" via email (Nodemailer).
- **🌙 Dark/Light Mode:** Fully responsive, modern UI with smooth Framer Motion animations.

## 🛠️ Tech Stack

**Frontend:**
- React.js (Vite)
- Tailwind CSS (Custom Design System)
- Zustand (State Management)
- Recharts (Real-time Charting)
- Framer Motion (Animations)

**Backend:**
- Node.js & Express.js
- MongoDB Atlas (Database)
- Mongoose (ODM)
- JWT (Authentication)
- Groq SDK (AI Integration)

**Deployment:**
- Frontend: Vercel
- Backend: Render 

## ⚠️ Disclaimer
EquiLearn is strictly an **educational platform**. All trading is simulated (paper trading), and no real money is involved. The AI assistant does not provide financial advice. Always consult a SEBI-registered advisor before investing in real markets.
